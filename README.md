# What is this website?

Why, it's a site that contains original games about "horses."

# Local setup

```
npm start
```

# Compiling for gh-pages

```
npm run deploy
```

# I am here to find out horse merge logic. Where do I go?

Look in `src` > `utils` > `horseFunctions`. The `utils` folder is your friend if you want to find out how this stuff works (also if you want to get a sneak peek at what lies ahead in the coming weeks).
